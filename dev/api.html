ParticleTransport.prepare Method
julia
prepare(;
    u = nothing, B = nothing,
    kappa = ZeroDiffusion(), dpp = ZeroMomentumDiffusion(),
    dmu = ZeroPitchAngleDiffusion(),
    model = ParkerTransport(), coords = CartesianCoordinates(),
    species = Proton, q = nothing, m = nothing, c = C_SI,
    dims::Int = 3, drift::Bool = false,
    track_3rd_dim::Bool = false, acc_region = nothing, type = nothing
)

Build a TransportParams (for ParkerTransport) or FocusedTransportParams (for FocusedTransport) struct in dims ∈ (1, 2, 3) dimensions.

  • u, B: Analytical callables f(x) or f(x, t), interpolators from build_interpolator, LazyTimeInterpolator, or nothing (zero field).

  • kappa: Spatial diffusion model (ZeroDiffusion, IsotropicDiffusion, ConstantDiffusion, PowerLawDiffusion, QLTDiffusion, NLGCDiffusion, CustomDiffusion, or a callable (x, p, t) -> (kpara, kperp)).

  • dpp: Momentum diffusion model (ZeroMomentumDiffusion, PowerLawMomentumDiffusion, AlfvenWaveMomentumDiffusion, FlowShearMomentumDiffusion, CustomMomentumDiffusion, or a callable (x, p, t) -> Dpp).

  • dmu: Pitch-angle diffusion model (used when model isa FocusedTransport).

  • model: ParkerTransport() (default) or FocusedTransport().

  • coords: CartesianCoordinates() (default) or SphericalCoordinates().

  • species, q, m, c: Particle species (default Proton in SI units).

  • drift: Include guiding-center magnetic drift.

  • track_3rd_dim: When dims == 2, evolve the 3rd spatial coordinate (z) while keeping spatial field derivatives 2D (∂/∂z = 0).

  • acc_region: Optional acceleration-region mask (nothing, a box tuple ((xmin, xmax), ...), BoxAccelerationRegion, or predicate f(x, t) -> Bool).
