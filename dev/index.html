ParticleTransport.jl ​

ParticleTransport.jl solves energetic particle transport and acceleration equations in magnetized plasmas using forward-in-time stochastic differential equations (SDEs) built on SciMLBase and StochasticDiffEq.jl.

Inspired by xiaocanli/stochastic-parker (GPAT) and structured alongside TestParticle.jl, it provides a macroscopic diffusive transport solver that complements microscopic Lorentz and guiding-center orbit tracing.

Capabilities ​

  • 1D/2D/3D Cartesian Parker Transport: Forward-in-time Itô SDEs in with anisotropic spatial diffusion (), plasma convection (), adiabatic/compressional acceleration ( ), momentum diffusion (), and guiding-center magnetic drifts ().

  • Analytical & Gridded MHD Fields: Define and as analytical functions (differentiated automatically via ForwardDiff.jl) or interpolated from gridded MHD arrays via FastInterpolations.jl.

  • Native SciML Integration: Constructs standard SciMLBase.SDEProblem and EnsembleProblem objects solved with StochasticDiffEq.jl (EM, SRIW1, EnsembleThreads, etc.).

  • Boundary Conditions & Particle Splitting: Composable SciML callbacks for absorbing, periodic, reflecting, and momentum boundaries, plus a weight-conserving generational particle splitter (solve_with_splitting) for steep high-energy power-law tails.

  • Diagnostics: Weighted momentum spectra and spatial profiles , including -memory streaming ensemble reductions.

Quick Start ​

julia
julia> using ParticleTransport, StochasticDiffEq, StaticArrays

julia> u(x) = SA[1.5 - 0.5 * tanh(x[1] / 0.1), 0.0, 0.0];

julia> B(x) = SA[1.0, 0.0, 0.0];

julia> param = prepare(; u, B, kappa = ConstantDiffusion(0.1, 0.0), dims = 1);

julia> u0 = make_state(0.0, 1.0);

julia> prob = TransportProblem(u0, (0.0, 1.0), param);

julia> sol = solve(prob, EM(); dt = 1.0e-3);

julia> sol.retcode == StochasticDiffEq.ReturnCode.Success
true
