ParticleTransport.TransportProblem Method
julia
TransportProblem(u0, tspan, param::TransportParams; kwargs...)

Construct a standard SciMLBase.SDEProblem for Parker's transport equation.

  • When u0 is an SVector{4}, builds an out-of-place SDEProblem{false} using parker_drift and parker_diffusion with SMatrix{4, 4} noise prototype.

  • When u0 is a mutable AbstractVector of length 4, builds an in-place SDEProblem{true} using parker_drift! and parker_diffusion! with a 4×4 matrix noise prototype.

Additional keyword arguments are forwarded directly to SciMLBase.SDEProblem.

ParticleTransport.parker_drift Method
julia
parker_drift(u, param::TransportParams, t)

Out-of-place drift vector SVector{4} for the forward-in-time Parker transport SDE in u = (x, y, z, ln p):

  • dx/dt = u_flow + v_d + ∇ ⋅ κ (masked to active dims)

  • d(ln p)/dt = -(1/3) ∇ ⋅ u_flow + (1/p²) ∂(p D_pp)/∂p

ParticleTransport.prepare Method
julia
prepare(;
    u = nothing, B = nothing,
    kappa = ZeroDiffusion(), dpp = ZeroMomentumDiffusion(),
    species = Proton, q = nothing, m = nothing, c = C_SI,
    dims::Int = 3, drift::Bool = false, type = nothing
)

Build a TransportParams struct for Parker's transport equation in dims ∈ (1, 2, 3) Cartesian dimensions.

  • u, B: Analytical callables f(x) or f(x, t), interpolators from build_interpolator, LazyTimeInterpolator, or nothing (zero field).

  • kappa: Spatial diffusion model (ZeroDiffusion, IsotropicDiffusion, ConstantDiffusion, PowerLawDiffusion, CustomDiffusion, or a callable (x, p, t) -> (kpara, kperp)).

  • dpp: Momentum diffusion model (ZeroMomentumDiffusion, PowerLawMomentumDiffusion, CustomMomentumDiffusion, or a callable (x, p, t) -> Dpp).

  • species, q, m, c: Particle species (default Proton in SI units). Pass q, m, c explicitly (or c = Inf for non-relativistic kinematics) for dimensionless/normalized runs.

  • drift: Include guiding-center magnetic drift v_d = (p v / 3q) ∇ × (B / B²).
